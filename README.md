# 4-bit Arithmetic Logic Unit (ALU)

This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL in Xilinx Vivado.

## Features
- Addition
- Subtraction
- AND
- OR
- XOR
- NOT
- Left Shift
- Right Shift

## Tools Used
- Verilog HDL
- Xilinx Vivado 2017.4

## Results
Successfully verified using behavioral simulation and RTL schematic.
